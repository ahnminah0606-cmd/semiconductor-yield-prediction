# 반도체 공정 데이터 분석 | SECOM 불량 탐지 평가

공개 반도체 제조 데이터를 Python으로 전처리하고, 클래스 불균형 환경에서 XGBoost의 불량 탐지 성능을 평가한 학습 프로젝트입니다. 높은 정확도만으로 모델을 판단하지 않고 **미탐(FN)과 오경보(FP)를 구분해 결과의 한계를 설명하는 것**에 초점을 두었습니다.

- [분석 과정과 그래프 보기](https://ahnminah0606-cmd.github.io/semiconductor-yield-prediction/projects/01-secom.html)
- [전체 분석 포트폴리오](https://ahnminah0606-cmd.github.io/semiconductor-yield-prediction/)
- [SECOM 실행 노트북](01.secom_yield_prediction.ipynb)

이 저장소에는 SECOM 외에도 공정·웨이퍼 데이터 분석 노트북이 있습니다. 아래 수치와 설명은 SECOM 노트북에 한정합니다.

## 수행 내용

- 결측률과 클래스 분포를 확인하고 결측값 처리 및 변수 선별
- 정상·불량 비율을 유지한 학습/테스트 분할, SMOTE 및 표준화 적용
- Recall 기준 GridSearchCV로 XGBoost 파라미터 비교
- 혼동행렬과 클래스별 Precision·Recall·F1-score로 결과 해석
- 분석 과정과 그래프를 웹 포트폴리오로 정리

## 데이터와 분석 절차

| 항목 | 내용 |
| --- | --- |
| 데이터 | UCI SECOM 기반 공개 데이터, 저장소의 `uci-secom.csv` |
| 샘플·입력 센서 | 1,567개 샘플, 590개 센서 변수 |
| 클래스 분포 | 정상 1,463건, 불량 104건 |
| 결측값 처리 | 결측률 40% 초과 변수 제거, 나머지 수치형 결측값 중앙값 보정 |
| 변수 선별 | VarianceThreshold(0.05) 적용 후 267개 |
| 모델 | Recall 기준 GridSearchCV + XGBoost |
| 테스트셋 | 314건: 정상 293건, 불량 21건 |

현재 노트북의 처리 순서는 결측값 처리 → 변수 선별 → 학습/테스트 분할 → 학습 데이터 SMOTE → 표준화 → GridSearchCV → 테스트 평가입니다. 이 순서의 검증상 한계는 아래에 명시했습니다.

전체 정확도는 높지만 실제 불량 21건을 모두 정상으로 분류했습니다. **현재 모델은 불량 선별에 사용할 수 없습니다.** 이 결과는 정확도만으로 불균형 데이터의 성능을 판단하면 안 된다는 한계를 보여줍니다.

## 결과 해석과 현장 업무에 연결되는 관점

- 21건은 오경보가 아니라 실제 불량을 놓친 미탐(FN)이며, 오경보(FP)는 5건입니다.
- 불량을 놓치는 경우와 정상 제품을 불량으로 판단하는 경우를 구분해 평가해야 합니다.
- Feature Importance는 모델 내 예측 기여도이며, 실제 불량 원인을 증명하지 않습니다.
- 센서의 물리적 의미와 장비·챔버 이력이 확인되지 않은 상태에서 특정 챔버의 원인을 역추적했다고 주장하지 않습니다.
- 장비 현장 업무에서도 측정값·판단 기준·추가 확인 사항을 구분하는 관점으로 연결할 수 있습니다. 다만 이 프로젝트는 공개 데이터를 이용한 학습이며, 실제 고객 장비 복구나 수율 개선 실적은 아닙니다.

이전 README에 있던 Recall 0.12/0.68/0.82, LightGBM 및 핵심 센서 35개 성과는 현재 노트북에서 확인되지 않아 제외했습니다.

## 현재 실험의 한계와 후속 개선 계획

현재 노트북은 결측치 보정과 VarianceThreshold를 데이터 분할 전에 수행하고, SMOTE를 교차검증 전에 적용합니다. 평가 데이터의 정보가 전처리에 반영되거나 교차검증 점수가 낙관적으로 평가될 위험이 있으므로 현재 결과를 독립적인 일반화 성능으로 확정하지 않습니다.

아래는 **아직 완료하지 않은 후속 실험 계획**입니다.

1. 원본 데이터를 먼저 학습/검증/테스트로 분리합니다.
2. 학습 폴드 안에서만 전처리·변수 선별·SMOTE를 적용하도록 Pipeline을 구성합니다.
3. 검증 데이터에서 모델과 임계값을 비교하고, 불량 Recall과 오경보를 함께 평가합니다.
4. 최종 테스트셋은 모델 선택에 사용하지 않고 마지막 평가에 사용합니다.

## 노트북 실행 방법

Python과 Jupyter 환경에서 저장소 루트를 작업 폴더로 사용합니다.

```bash
python -m pip install pandas numpy scikit-learn imbalanced-learn xgboost matplotlib seaborn jupyter
jupyter notebook 01.secom_yield_prediction.ipynb
```

`uci-secom.csv`와 노트북을 같은 폴더에 둔 뒤 셀을 위에서부터 실행합니다. GridSearchCV는 실행 시간이 걸릴 수 있습니다. 패키지 버전이 고정되어 있지 않아 환경에 따라 결과가 달라질 수 있습니다.
