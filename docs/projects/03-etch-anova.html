PROJECT 03

Etch Chamber ANOVA

Etch Chamber 간 공정 결과 차이를 통계적으로 검증한 프로젝트입니다.

Analysis Objective

반도체 공정 데이터를 Python으로 분석하고, 공정 특성과 품질 및 수율에 영향을 주는 요인을 데이터 기반으로 확인하는 것을 목적으로 합니다.

Tools

Python Pandas NumPy Matplotlib Jupyter Notebook

Analysis Result

이 영역에는 해당 Jupyter Notebook에서 생성한 실제 그래프와 분석 결과를 추가할 예정입니다.

Engineering Insight

분석 결과를 공정 관점에서 해석하고, 이상 원인 탐색 및 공정 개선에 활용할 수 있는 인사이트를 정리합니다.
