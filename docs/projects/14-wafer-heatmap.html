PROJECT 14

Interactive Wafer Heatmap

Wafer Die의 X/Y 좌표와 수율 점수를 Plotly Heatmap으로 시각화하여 불량의 공간적 분포를 브라우저에서 직접 탐색할 수 있도록 구현한 인터랙티브 분석 프로젝트입니다.

Analysis Objective

Wafer의 평균 Yield만으로는 불량이 실제로 어느 위치에 집중되어 있는지 파악하기 어렵습니다.

핵심 목표

각 Die의 X/Y 좌표에 Yield Score를 매핑하여 Wafer 형태의 Heatmap을 생성하고, Hover 기능을 통해 개별 Die의 위치, 수율 점수, PASS/FAIL 상태를 직접 확인할 수 있도록 구현합니다.

Heatmap Design

Wafer Coordinate Grid

X/Y 좌표를 기준으로 2차원 Grid를 생성하고 Wafer Radius 내부의 Die에만 수율 값을 할당했습니다. Wafer 외부 영역은 NaN으로 처리하여 실제 Wafer 형태가 나타나도록 구성했습니다.

Yield Score

각 Die에는 0~100 범위의 Yield Score를 부여하고 값이 낮을수록 불량 위험이 높은 영역, 값이 높을수록 정상 영역으로 표현했습니다.

Color Scale

낮은 Yield Score는 Red 계열, 중간 영역은 Yellow, 높은 Yield Score는 Green 계열로 표시하여 이상 영역을 빠르게 구분할 수 있도록 구성했습니다.

PASS / FAIL

Yield Score 70을 기준으로 PASS와 FAIL 상태를 구분하고, Hover 시 해당 Die의 판정 결과를 함께 확인할 수 있도록 했습니다.

Defect Pattern Simulation

Ring Pattern
Wafer Edge 영역의 Yield Score를 낮게 설정하여 가장자리 불량 패턴을 구현했습니다.

Center Pattern
Wafer 중심 영역의 Yield Score를 낮게 설정하여 중심부 집중 불량을 구현했습니다.

Random Pattern
전체 Wafer에서 일부 Die에 임의의 낮은 값을 부여하여 불규칙한 불량 분포를 구현했습니다.

Interactive Analysis

Die-level Hover

Heatmap의 각 셀에 마우스를 올리면 Die X 좌표, Y 좌표, Yield Score, PASS/FAIL 상태를 확인할 수 있습니다.

Multi-Wafer Comparison

여러 Wafer를 Subplot 형태로 배치하여 Lot과 Wafer별 불량 패턴을 한 화면에서 비교할 수 있도록 구성했습니다.

Browser-based Exploration

결과를 Plotly HTML 파일로 저장하여 별도의 Python 실행 환경 없이도 브라우저에서 인터랙티브 분석 결과를 확인할 수 있습니다.

Engineering Insight

Edge 불량 탐지

Wafer Edge에서 반복적으로 낮은 Yield Score가 나타나는 경우 위치 의존적인 공정 편차가 존재하는지 우선적으로 확인할 수 있습니다.

Center 불량 탐지

중심부에 낮은 Yield가 집중되는 경우 공정 조건의 중심부 편차나 공간적 균일도 문제를 원인 후보로 검토할 수 있습니다.

Lot / Wafer 비교

여러 Wafer의 Heatmap을 동시에 비교하면 동일 패턴이 반복되는지 확인할 수 있어 Lot 단위 이상 분석에 활용할 수 있습니다.

공정 데이터 연계

실제 제조 환경에서는 Wafer Map을 Tool, Chamber, Recipe 및 공정 이력과 함께 분석하여 반복되는 공간적 불량 패턴의 원인 후보를 좁혀가는 방식으로 확장할 수 있습니다.
