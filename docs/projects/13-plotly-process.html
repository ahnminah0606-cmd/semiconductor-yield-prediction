PROJECT 13

Interactive Process Analysis

Plotly를 활용하여 반도체 공정 파라미터 간의 관계를 브라우저에서 직접 탐색할 수 있도록 구현한 인터랙티브 데이터 시각화 프로젝트입니다.

Analysis Objective

정적인 그래프는 전체적인 경향을 확인하기에는 유용하지만, 특정 공정 조건의 세부 값을 직접 확인하기에는 한계가 있습니다.

핵심 목표

Temperature, Pressure, Gas Flow, Thickness와 같은 공정 변수를 하나의 Scatter Matrix에서 비교하고, 마우스 Hover 및 Zoom 기능을 활용해 개별 데이터 포인트를 직접 탐색할 수 있도록 구현합니다.

Analysis Result

1. 공정 변수 동시 비교

Scatter Matrix를 이용하여 여러 공정 변수의 두 변수 조합을 한 화면에서 동시에 비교하도록 구성했습니다.

2. PASS / FAIL 구분

Thickness가 목표 범위에 들어오는지를 기준으로 PASS와 FAIL을 구분하고 색상으로 시각화했습니다.

3. Equipment 구분

CVD_01, CVD_02, CVD_03 설비를 서로 다른 Symbol로 표시하여 설비별 데이터 분포 차이를 동시에 확인할 수 있도록 했습니다.

4. Interactive Exploration

Plotly의 Hover, Zoom, Pan 기능을 이용해 특정 데이터 포인트의 공정 조건을 직접 확인할 수 있습니다.

Engineering Insight

EDA 효율 향상

여러 개의 개별 Scatter Plot을 하나씩 확인하는 대신 Scatter Matrix를 사용하면 공정 변수 간 관계를 빠르게 탐색할 수 있습니다.

설비별 분포 비교

Equipment 정보를 함께 표현하면 특정 설비에서만 데이터 분포가 치우치거나 FAIL이 집중되는지 시각적으로 확인할 수 있습니다.

웹 기반 분석 공유

Plotly 결과를 HTML 파일로 저장하면 Python 환경 없이도 브라우저에서 동일한 분석 결과를 확인할 수 있어 포트폴리오 및 분석 공유에 활용할 수 있습니다.
